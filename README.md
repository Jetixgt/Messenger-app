1. Скачайте архив со сборкой или установщик приложения.
2. Если это папка сборки, распакуйте её полностью.
3. Откройте папку Web-mes.
4. Запустите файл super_app_error.exe.
5. Если Windows покажет предупреждение безопасности, нажмите "Подробнее" → "Выполнить в любом случае".
6. Не удаляйте и не перемещайте файлы рядом с .exe, приложение зависит от них.
